# ST Chip Switch Reference / ST 换芯片速查表

When switching the target MCU series, update the following fields. / 更换目标芯片系列时，修改以下字段。

> The template provides pre-built configs for **F1** and **F4**. If you are switching between these two, use the existing config pair (e.g. from `F4-debug` to `F1-debug`) — just pick the right launch config in VS Code. If you are switching to a series not covered by the template (H7, G0, L4, etc.), follow GUIDE.md §14.1 to create new configs. / 模板提供 **F1** 和 **F4** 的预置配置。如果在这两者之间切换，直接用已有的配置对即可（如从 `F4-debug` 切到 `F1-debug`）。如果切换到模板未覆盖的系列（H7、G0、L4 等），参考 GUIDE.md §14.1 创建新配置。

## Mac: Profile `settings.json` / Mac 端 Profile 配置文件

> **Win**: IntelliSense is auto-synced by `configurationProvider: ms-vscode.cmake-tools` — no manual `includePath`/`defines` changes needed. However, the **launch config and Flash task** still need changes (see below). / Win 端 IntelliSense 由 `configurationProvider` 自动同步，无需手动改 `includePath`/`defines`。但 **launch 配置和 Flash 任务**仍需修改（见下节）。

### F4 → F1（e.g. STM32F407 → STM32F103 / 例：STM32F407 → STM32F103）

| Field / 字段 | Before / 改前 | After / 改后 |
|-------------|--------------|--------------|
| `C_Cpp.default.defines[0]` | `STM32F407xx` | `STM32F103xB` |
| `C_Cpp.default.includePath[2]` | `.../STM32F4xx_HAL_Driver/Inc` | `.../STM32F1xx_HAL_Driver/Inc` |
| `C_Cpp.default.includePath[3]` | `.../STM32F4xx_HAL_Driver/Inc/Legacy` | `.../STM32F1xx_HAL_Driver/Inc/Legacy` |
| `C_Cpp.default.includePath[4]` | `.../STM32F4xx/Include` | `.../STM32F1xx/Include` |

### F4 → H7（e.g. STM32F407 → STM32H743 / 例：STM32F407 → STM32H743）

| Field / 字段 | Before / 改前 | After / 改后 |
|-------------|--------------|--------------|
| `C_Cpp.default.defines[0]` | `STM32F407xx` | `STM32H743xx` |
| `C_Cpp.default.includePath[2]` | `.../STM32F4xx_HAL_Driver/Inc` | `.../STM32H7xx_HAL_Driver/Inc` |
| `C_Cpp.default.includePath[3]` | `.../STM32F4xx_HAL_Driver/Inc/Legacy` | `.../STM32H7xx_HAL_Driver/Inc/Legacy` |
| `C_Cpp.default.includePath[4]` | `.../STM32F4xx/Include` | `.../STM32H7xx/Include` |

## Win: Launch Config & Flash Task / Win 端 Launch 配置与 Flash 任务

> Each STM32 series uses a **different OpenOCD target cfg** (e.g. `stm32f1x.cfg`, `stm32f4x.cfg`, `stm32h7x.cfg`). The `interface/stlink.cfg` does NOT change as long as you use ST-Link. / 每个 STM32 系列使用**不同的 OpenOCD target cfg**（如 `stm32f1x.cfg`、`stm32f4x.cfg`、`stm32h7x.cfg`）。只要使用 ST-Link，`interface/stlink.cfg` 不变。

### Switching between F1 ↔ F4 / F1 ↔ F4 之间切换

Use the existing Flash/debug config pair in the template — no new configs needed. In `settings.json`, pick the matching launch config (`F1-flash` / `F1-debug` or `F4-flash` / `F4-debug`). The Flash task label in `tasks.json` must match the Flash wrapper's `preLaunchTask`. / 使用模板现有的 Flash/debug 配置对，无需新建。在 `settings.json` 中选择匹配的 launch 配置（`F1-flash` / `F1-debug` 或 `F4-flash` / `F4-debug`）。`tasks.json` 中 Flash 任务标签需与 Flash 包装配置的 `preLaunchTask` 对应。

### Switching to H7 / G0 / L4 / etc. / 切换到 H7 / G0 / L4 等未覆盖系列

Two files need changes / 需修改两个文件：

**`settings.json`** — copy an existing debug + Flash wrapper pair, then update:

| Field / 字段 | How to change / 修改方式 |
|-------------|------------------------|
| `name` | `{series}-debug` / `{series}-flash` |
| `device` | Debug only: target MCU identifier, e.g. `STM32H743ZI` / 仅 debug：目标芯片型号 |
| `configFiles` target | Debug only: e.g. `stm32h7x.cfg` — browse `<path-to-openocd>/openocd/scripts/target/` / 仅 debug：在 OpenOCD scripts/target/ 下查看正确文件名 |
| `svdFile` | Debug only: `${workspaceFolder}/STM32H7xx.svd` / 仅 debug |
| `preLaunchTask` | Flash wrapper: new Flash task label; debug: `Build` / Flash 包装配置匹配新任务标签；debug 使用 `Build` |

**`tasks.json`** — copy an existing Flash task, then update:

| Field / 字段 | How to change / 修改方式 |
|-------------|------------------------|
| `label` | e.g. `Flash (H7)` — must match Flash wrapper's `preLaunchTask` / 需与 Flash 包装配置的 `preLaunchTask` 一致 |
| `args` target cfg | e.g. `-f target/stm32h7x.cfg` |

See GUIDE.md §14.1 for a detailed walkthrough. / 详细步骤见 GUIDE.md §14.1。

## Notes / 说明

| Item / 项目 | Notes / 说明 |
|------------|-------------|
| `USE_HAL_DRIVER` / `DEBUG` | Unchanged / 不变 |
| CMakeLists.txt, linker script, HAL drivers / 链接脚本、HAL 驱动 | Regenerated by CubeMX / CubeMX 重新生成 |
| `interface/stlink.cfg` / ST-Link 接口 cfg | Unchanged as long as using ST-Link / 使用 ST-Link 则不变 |
| After switching / 换芯片后 | F6 full rebuild / F6 全量重编 |
